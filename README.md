ETF Directional Bias Prediction Using Technical Indicators

Collected and processed historical ETF market data using yfinance, engineered 100+ technical indicators with pandas-ta, and constructed a forward-shifted classification target to predict next-period directional movement.

Built an end-to-end machine learning pipeline including data cleaning, MinMax feature scaling, correlation-based feature selection, and dimensionality reduction to improve signal quality and reduce noise.

Trained and evaluated a Neural Network (MLPClassifier) using Stratified K-Fold cross-validation, benchmarking baseline vs. top-ranked feature subsets and measuring model performance using accuracy metrics.
